Background

All functions in R have at least 3 things:

  • a name (we pick that and use it to call the function)
  • input arguments (one or more comma separated inputs that go inside the brackets when we call the function)
  • the body (the lines of R code that do the work of the function)

A generate DNA function

Write a function generate_dna() that returns a random DNA sequence of a length specified by the user.

Q2a. Your first version should return a multi-element vector of single character nucleotides. For example generate_dna(6) might return “A”, “T”, “T”, “G”, “A”, “C”. [1 pt]

Useful base R functions that you may (or may not) find useful for this lab include: sample(), paste(), paste0(), if(), for(), sapply(), nchar(), and cat().

The sample() function looks useful. There are two required arguments (i.e. inputs I must give that don’t have a default value)

sample(x = 1:10, size = 4)
[1] 3 7 6 2

We can use this with “A”, “C”, “G”, and “T” as input x to make random nucleotide sequences

sample(x = c("A", "C", "G", "T"), size = 5, replace = TRUE)
[1] "A" "C" "G" "A" "T"

Cool! We have a working snipet of code that does something useful! this can serve as the “body” of our first generate_dna() function.

generate_dna <- function(n){
  sample(x = c("A", "C", "G", "T"), size = n, replace = TRUE)
}
generate_dna(6)

generate_dna <- function(n, choice = FALSE){
  #Generate if statement to give person an option/choice
  if(choice == TRUE){
    #Multi-element nucleotide vector
    sample(x = c("A", "C", "G", "T"), size = n, replace = TRUE)
  } else if (choice == FALSE){
    s <- sample(x = c("A", "C", "G", "T"), size = n, replace = TRUE)
    #Make a single element vector
    paste(s, collapse = "")
  }
  #Just incase the code doesn't run
  else{
    print("Try (6, TRUE)")
  }
}
